# Personal Developer Portfolio

A moderate, human-designed multi-page portfolio built with plain HTML and CSS.

## Files

- `index.html` — Home / developer introduction
- `about.html` — About Me / education / journey
- `gallery.html` — Projects & work showcase
- `contact.html` — Contact / connect
- `style.css` — Shared responsive design system

## Personalization checklist

Before publishing, replace:
- `Your Name`
- `YN` / `Y` initials
- Profile photo placeholder
- Education and college details
- Career goal
- Personal introduction
- Email
- GitHub
- LinkedIn
- Location
- Project repository/demo links

## Run locally

Open `index.html` in a browser or use VS Code Live Server.
